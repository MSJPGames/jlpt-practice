ぼうさいクイズ 一式（14言語・編集ページつき）
========================================

【入っているファイル】

  bousai_game.html   ゲーム本体（14言語の用語表示を追加）
  bousai_data.js     データ（問題20・警戒レベル5・ことば18・多言語）
  bousai_edit.html   編集ページ（自分用）
  og_bousai.png      SNS用のカード画像
  games.html         あそび場（カードを1枚追加）

  すべて jlpt-practice フォルダに置いてください。画像も同じ場所です。
  ★ 前の bousai_pack.zip / bousai_full.zip / bousai_all.zip は不要です。


────────────────────────────────────────
14言語について
────────────────────────────────────────

  送っていただいた気象庁の「多言語辞書」から入れました。
  ありがとうございました。これで根拠のある形になりました。

  言語（14）
    英語・简体中文・繁體中文・韓国語・ポルトガル語・スペイン語・
    インドネシア語・ベトナム語・タガログ語・タイ語・ネパール語・
    クメール語・ビルマ語・モンゴル語

  右上の 🌐 ボタンで切り替えます。
  日本語は消えません。下に母語が出る形です。

  【訳が入ったもの（◯印つき）】
    ・警戒レベル 1〜5（全言語）
    ・避難／高齢者等避難
    ・津波警報・大津波警報・津波注意報
    ・緊急地震速報
    ・土砂災害／土砂災害警戒情報
    ・高潮／大雨／大雨注意報
    ・地震情報／台風情報
    ・2026年からの新名称（レベル４高潮危険警報 など）

  【まだ訳が無いもの】
    避難所・避難場所・避難指示・緊急安全確保・断水・給水・停電・
    炊き出し・安否確認・立入禁止・ハザードマップ・余震

    これらは気象庁の辞書に無い語です（市区町村や避難所の用語のため）。
    内閣府・消防庁も15言語の防災用語を作っているので、
    次にそれを当たれば埋められます。

    ★ 訳の無いものには ◯印を付けていません。
      「どれが公的な訳で、どれがそうでないか」が
      画面で見て分かるようにしてあります。


────────────────────────────────────────
出典の表示について
────────────────────────────────────────

  気象庁ホームページの利用規約は
  「公共データ利用規約（第1.0版）」に準拠しており、
  翻訳・翻案・商用利用が可能です。条件は出典の記載と、
  編集・加工したことの記載です。

  「ことば」の画面の下に、次を常時表示しています。

    ◯印の訳の出典：気象庁「多言語辞書」（2026年3月26日更新）
    https://www.data.jma.go.jp/developer/multilingual.html
    公共データ利用規約（第1.0版）に準拠。出典表示のうえ利用。
    気象庁の資料を加工して作成しています。

  規約が求める「編集・加工を行ったことの記載」も入れてあります。
