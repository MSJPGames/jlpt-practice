【おわびと訂正】
 前回のREADMEで「sitemap.xml は 2026-07-29 のままで、bunkei/ が未登録」と
 書きましたが、これは**まちがい**でした。
 実物を数えたところ、sitemap.xml は 2026-08-04 に作り直されていて、
 **711 URL（ルート257・クエリ付き50・learn 97・bunkei 307）**が正しく入っていました。
 プロジェクトの古いメモを見て書いてしまいました。失礼しました。

 ほんとうに足りなかったのは、**今回あたらしく作った文型ページ129枚だけ**です。

【この sitemap.xml の中身】
   もと      711 URL
   足したぶん 129 URL（bunkei/ の新しいページ）
   ──────────────
   合計      840 URL

   内訳：ルート 257 ／ クエリ付き 50 ／ learn 97 ／ bunkei 436

 ・bunkei.html（ハブ）は中身が変わったので、lastmod を今日に更新しました。
 ・ほかのページの lastmod は、もとのまま1つも変えていません。
 ・XMLとして読み直して、840URL・重複0・bunkei 436枚の もれ0 を確認ずみです。

【もう一つのやり方（こちらでもかまいません）】
 パソコンの「JLPT PRACTICE」フォルダにある

     make_sitemap.bat

 をダブルクリックしても、同じものができます。
 こちらは**実際のファイルを見て作る**ので、私が知らないページが増えていても
 きちんと拾ってくれます。どちらか片方で大丈夫です。
 （このスクリプトは sitemap_backup.xml に退避してから上書きします。）

【順番のお願い】
 先に **bunkei_kaisetsu_129.zip の中身**（bunkei.html と bunkei/ の129枚）を
 アップロードしてから、この sitemap.xml を上げてください。
