N5 聴解の音声を作る（全部作り直します）

【今回のこと】
  N5の聴解を本試験の形にそろえ、24問から72問に増やしました。
  台本が変わったので、**72本すべてを作り直します**。20分ほどです。

  もんだい1 課題理解    21問  n5_q1_01 ～ n5_q1_21
  もんだい2 ポイント理解 18問  n5_q2_01 ～ n5_q2_18
  もんだい3 発話表現    15問  n5_q3_01 ～ n5_q3_15
  もんだい4 即時応答    18問  n5_q4_01 ～ n5_q4_18

  直したところ
  ・場面か設問が音声に入っていなかった18問に、ナレーターを入れました
  ・会話の前に設問を読んでいなかった13問を、本試験どおり「場面 → 設問 → 会話 → 設問」に
  ・発話表現を公式の形に作り直しました（発話0回＋選択肢3つを音声で読む）
  ・即時応答も選択肢を音声で読むようにしました
  ・アナウンスや放送などの「一人語り」を9問入れました（公式は課題理解の29%）

【要るもの】
  Python 3 と edge-tts（.bat が自動で入れます）
  同じフォルダに次の3つ：
    make_n5_listening_audio.py
    n5_listening_manifest.json
    file_to_daimon.json

【やりかた】
  1) この3つを「JLPT PRACTICE」フォルダに置く
  2) make_n5_listening_audio.bat をダブルクリック
  3) 待つ（72本で20分ほど）
  4) audio フォルダの n5_q*.mp3 を、HTMLと同じ場所に置いてGitHubへ

  ★古い n5_q1_08.mp3 のような、いま使っていないファイルは残っていてもかまいません。
    HTMLはマニフェストにあるファイルしか呼びません。

【確かめること】
  ・ログの最後が failed 0 になっていること
  ・audio フォルダの n5_q*.mp3 が 72本あること
  ・どのファイルも 144バイトの倍数であること（壊れたmp3は倍数になりません）

【間（ま）の長さについて】
  N1～N5で共通です（2026-08-16に決めました）。n5_audio_timing.json をご覧ください。
