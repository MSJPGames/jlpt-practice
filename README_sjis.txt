■ 何を直したか

(1) 文の文法1・文章の文法 1617問 ― 「なぜ他の3つではだめか」を全問に入れた
    これまでは正解の形の意味しか書いていませんでした（N4は平均32字）。
    学習者が文法でいちばん知りたいのは**文型の使い分け**なので、そこを書きました。
    ・正解の形を「」で引いて、意味と使い方
    ・**まちがいの3つの形もそれぞれ「」で引いて**、なぜここでは使えないか
        「意味がちがう」「前につく形（接続）が合わない」
        「後ろに続く言い方と合わない」「話し手の立場・場面が合わない」
    ・選択肢を番号で呼ぶのはやめました（画面では並べ替わるため、番号はずれます）
    ・文章の文法は、空欄の前後のつながり（逆接・順接・言いかえ・例示）から説明
    → 誤答の説明あり 305問（19%）→ 1617問（100%）／平均 61字 → 128字

(2) 並べかえ（文の文法2）516問 ― 「なぜその順番になるのか」を入れた
    これまでは「正しい語順」と★の位置と文型名だけでした。
    並べかえは「どのことばがどのことばにつくか」が分かれば解けるので、
    4つのことばのうち3つ以上を「」で引いて、係り方を書きました。
    「～は～の目的語なのですぐ前」「～と～はセットで使う」「～は～を修飾する」など。
    → 平均 71字 → 146字

(3) ★作問のまちがいを25問見つけて直しました
    今回、解説を書く過程で**問題そのもののまちがい**が出てきました。
    　・並べかえ12問：解説に書かれた語順と、★の位置の正解が食いちがっていた
    　　（例：正しくは3番目が「使って」なのに、正解が「くれた」になっていた）
    　　→ 語順を確かめ、正解を直しました。肢の組み合わせでは文が作れないもの3問は
    　　　肢を作り直しました。
    　・文法13問：正解が2つ以上あるもの、日本語としておかしいもの
    　　（例：「昔（　）比べて」で「と」も「に」も正しい／
    　　　　　「べんきょうすると、じょうずになりたいです」という不自然な文）
    　　→ まぎれる肢を入れかえる、設問に一語足す、本文を直す、で1つに決めました。

    ★あわせて、並べかえ516問すべてについて、
      「解説に書いた語順」と「★の位置」と「正解」が合っているかを
      プログラムで検算する仕組みを作りました（516/516 合格）。
      今後、並べかえを足したときも同じように検算できます。
