貼り紙の多言語化 ＋ 危険なミスの説明（ご指摘の2件）
========================================

【入っているファイル】

  gomi_data.js    貼り紙用の訳を追加（曜日・袋の名前・注意文）
  gomi_rush.html  貼り紙に訳を出す＋危険なミスの説明パネル
  gomi_check.js   検査（手元用・サイトには置かない）

  gomi_data.js と gomi_rush.html を上書きしてください。


────────────────────────────────────────
① 貼り紙の英語 → 直しました
────────────────────────────────────────

  【原因】

  私が直した「掲示のことば」は 別画面の用語一覧 でした。
  貼り紙そのものとは繋がっていませんでした。

  貼り紙の中で訳が付いていたのは ごみの種類 だけ。
  曜日・袋の名前・注意文には付いていませんでした。

  データはあったのに、画面まで繋がっていなかった。
  私の検査はデータしか見ていませんでした。

  【直した内容】

  ・曜日（月〜日）      10言語
  ・袋の名前（7種類）    10言語
      とうめい・半とうめいの袋 → transparent or semi-transparent bag
      ひもで しばる           → tie up with string  など
  ・注意文（7本）        10言語
      前の日の夜に出さない／ネットをかける／粗大ごみは申し込みが必要／
      分けていないごみは回収できません／朝8時までに／夜12時までに／お休み

  日本語はそのまま残り、その下に小さく訳が出ます。
  貼り紙を「読む」練習なので、日本語を消してはいけないためです。

② 危険なミスの説明 → 直しました
────────────────────────────────────────

  【原因】

  モードによって挙動が違っていました。

    選択式（確認テスト） … 説明が出ていました（正常）
    生活型（流れてくる） … ポップアップだけで説明なし ← ここ

  ご覧になったのは生活型のほうだと思います。

  【直した内容】

  生活型でも、命にかかわるまちがいのときだけ
  画面を止めて説明を出すようにしました。

    🔥 あぶない！
    割れたガラスのコップ を「そのまま袋へ」はいけません。
    袋がやぶれて、集める人がけがをします。紙に包んで「キケン」と書きます。
    ⚠️ この出し方は、ごみ収集車やごみ処理場の火事・けがにつながります。
    ［わかった］

  ・危険フラグの付いたまちがいだけです。
    ふつうのミスはこれまでどおりポップアップだけで、流れは止まりません。
  ・パネルの間はゲーム内時間も止まります。閉じると再開します。

  安全を、ゲームの流れより優先しました。
