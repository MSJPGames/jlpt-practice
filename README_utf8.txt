■ 今回の変更（漢字読み 2,237問）
 ・訓読み 536問の誤答を、実在する日本語の語に入れ替えた
     いままでは「しつける」に対して「じつける／しつげる／しづける」のような、
     日本語に無いかな列が並んでいた（全体の73%）。
     これを「しかる／たしなめる／いましめる」のように、正解と同じ品詞・
     同じ意味分野の実在語に変えた。市販教材の作り方（同分野の類義語65%）に合わせたもの。
 ・音読み 1,701問の誤答に 2×2グリッドを入れた
     前の字を1軸（長音の有無・別の音）、後ろの字を1軸（清濁・拗音）動かした4通り。
     軸が直交しているので、学習者が「前を間違えたのか後ろを間違えたのか」を
     自分で確かめられる。
 ・送りがなの直し 11語
     受持ち→受け持ち、交す→交わす、口吟む→口ずさむ、素っ気無い→素っ気ない、
     情深い→情け深い、引下げる→引き下げる、引取る→引き取る、目覚しい→目覚ましい、
     夜更し→夜更かし、割込む→割り込む、断える→絶やす（「絶える」は既にあるため）
 ・解説を「「語」は「読み」。〈意味〉。」の形にそろえた
