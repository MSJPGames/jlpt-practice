  そのまま写さず、当サイトで訂正しました。

  ■ ライター（3言語すべて）

      公式PDF   pt: Escritor   es: Escritor   tl: Manunulat
      いずれも「書く人（writer）」の意味です。
      火をつける道具ではありません。

      訂正後   pt: Isqueiro   es: Encendedor   tl: Lighter

      日本語の「ライター」に writer と lighter の
      2つの意味があることに起因する取り違えです。
      なお浜松市のウェブページ側では isqueiro と
      正しく書かれているので、PDFだけの誤りです。

  ■ ストロー（タガログ語）

      公式PDF   Dayami（干し草）

  ■ スプレー缶（タガログ語）

      公式PDF   Latang pandilig（じょうろ）
      訂正後    Spray can

  【なぜ訂正したか】

    スプレー缶は 中身を使い切らないと収集車で燃える という、
    このゲームでいちばん教えたい品目のひとつです。
    それが「じょうろ」と表示されていては、意味がありません。

    公的資料だから正しい、とは限りませんでした。
