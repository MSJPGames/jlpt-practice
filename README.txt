【chinese_start.html】

  中国語話者向けの入口ページです。

  ・同じ形で同じ意味の語（12語）
  ・音読みが予測できること（広東語ならさらに有利）
  ・繁體 / 日本の新字体 / 大陸の簡体字 の三者比較（12組）
  ・同形異義語 18組  ← ここが中心
  ・中国語が助けにならない三つ（助詞・活用・敬語）
  ・サイト内の各ページへの導線

  繁體中文が主で、右上のボタンで日本語に切り替わります。
