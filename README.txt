【出典と、いま新しいところ】

  ・警戒レベルと避難情報の名称：内閣府／政府広報オンライン
    ※2021年5月の法改正で「避難勧告」は廃止され「避難指示」に一本化

  ・新しい防災気象情報：気象庁（2026年5月29日 運用開始）
    情報名称の前に警戒レベルの数字が付くようになりました。
    レベル4相当の「危険警報」が新設されています。
        レベル4大雨危険警報／レベル4土砂災害危険警報／
        レベル4高潮危険警報／レベル5大雨特別警報
    ※河川氾濫・大雨・土砂災害・高潮 以外はレベル表記なし

    ★ この変更は今年5月からなので、
      対応している外国人向け防災教材はまだほとんどありません。
      いま作ると、しばらく新しい状態でいられます。

  ・災害用伝言ダイヤル 171（NTT）

  画面には必ず「実際の災害時は住んでいる市区町村の指示に従ってください」
  と表示しています。


【多言語について】

  今回は やさしい日本語＋英語（ことばの表）だけです。
  ゴミ分別ゲームのような10言語対応は、まだ入れていません。

  理由：防災は誤訳が命に関わるので、公的な多言語資料を
  根拠にしたいところです。気象庁が防災用語の多言語辞書を
  出しているので、次にそれを当たれば同じやり方で足せます。
