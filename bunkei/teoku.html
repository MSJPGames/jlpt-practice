NIHONGO NO HEYA
〜ておく
do ~ in advance / leave as is
N3 動詞て形に付く 準備 放置
意味
準備あとのために、前もってする
放置そのままの状態をつづける
「〜ておく」は、動詞のて形に「おく」をつけた形です。一つめは、あとで何かをするために、いま前もってしておくという意味です。二つめは、目の前のものにさわらないで、そのままの状態をつづけるという意味です。どちらも「そのあとのことを考えて、いまこうすると自分できめる」ところが同じです。
コアイメージ
① 準備：あとのために、いまやっておく
② 放置：そのままの状態にしておく
上は準備、下は放置です。「いま動く」か「いま動かさない」かはちがいますが、あとのことを考えてきめるという芯は同じです。
接続
動詞て形 ＋ おく
ていねいな形は「〜ておきます」、過去は「〜ておきました」。話しことばでは「〜ておく」が「〜とく」、「〜でおく」が「〜どく」になります（買っとく・読んどく）。
いっしょに使うことば
前によく来る動詞（準備）
予約する調べる買うかたづける伝える
前によく来る動詞（放置）
開けるつける置くそのままにする
いっしょに使う副詞
前もってあらかじめ今のうちにとりあえず
例文
準備
会議の前に、資料をコピーしておきます。
I'll copy the handouts before the meeting.
準備
旅行に行く前に、行き方を調べておこう。
Let's look up how to get there before the trip.
準備
お客さんが来るので、飲み物を買っておいてください。
We have guests coming, so please buy some drinks beforehand.
放置
まだ使うので、パソコンはつけておいてください。
I'm still using it, so please leave the computer on.
放置
部屋が暑いから、まどは開けておこう。
The room is hot, so let's leave the window open.
話しことば
そのプリント、あとで読むから置いといて。
Leave that handout there — I'll read it later.
ほかの用法
①「〜ないでおく」＝ しないでそのままにする
わざと「しない」ほうをえらぶときの形です。
本人が話すまで、こちらからは聞かないでおこう。
②「〜ておいてください」＝ 前もってのお願い
あとのために、いまやってほしいと頼むときによく使います。
会場のいすは、その形のままにしておいてください。
にた文型とのちがい
〜てある
「〜ておく」はこれから自分がする動作、「〜てある」はもう終わっていて、目の前にある状態を言います。
〜ておく〜てある
言いたいことあとのためにするもうしてある状態
文の形〜を〜ておく〜が〜てある
する人これからする人がいるだれかがして、いまも残っている
会議の前に「資料をならべておく」＝これから自分がならべる。
会議室に入ると「資料がならべてある」＝もうならんでいる。
〜ている
「〜ておく」にはそのままにすると決めた人の気持ちがあります。「〜ている」はいまの様子を見たまま言うだけです。
〜ておく〜ている
言いたいことそのままにすると決めるいまそうなっている
人の意志あるない
例まどを開けておくまどが開いている
「エアコンをつけておく」＝消さないと自分できめた。
「エアコンがついている」＝いまの様子を言っただけ。
ほかのことばで
EN
〜ておく means doing something now for later (preparation), or deliberately leaving a situation as it is. In casual speech it shortens to 〜とく / 〜どく.
中文
「〜ておく」表示為了以後而事先做好某事，或是刻意讓某個狀態保持原樣、不去更動。口語中常縮成「〜とく／〜どく」。
