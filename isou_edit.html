位相チェッカー　編集

‹ ページを見る 🏠 トップ

直したら「書き出し」タブで isou_data.js をダウンロードし、GitHub の同じファイルを置きかえます。isou.html は触りません。書きかけはこのブラウザに自動で残ります。

サイトに反映させる手順
  1. 下の「isou_data.js を書き出す」を押す。ダウンロードフォルダに isou_data.js ができます
  2. GitHub の jlpt-practice を開き、Add file → Upload files を押す
  3. 書き出した isou_data.js をその画面にドラッグする。同じ名前なので古いほうが置きかわります
  4. 下までスクロールして Commit changes を押す
  5. 1〜2分あとに ページ を開いて確かめる
OneDrive の JLPT PRACTICE フォルダにも、同じファイルを入れておいてください。次に直すときの元になります。
