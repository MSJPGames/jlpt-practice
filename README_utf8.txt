【本文なしで解けてしまう問題 ― 第一段（機械で拾える手がかり132問）】

■ やったこと

　サイト全体から702問を抜き、本文も台本も見せずに設問と選択肢だけで解かせて、
　「読まなくても・聞かなくても解けてしまう」度合いを測りました（まぐれは25％）。
　そのうえで、手がかりを機械で拾える形にして（leak.py）、拾えたものを全部つぶしました。

　　⑥ 同じ本文の別の設問が、答えをそのまま漏らしている … 19問 → 0
　　⑤ 4本のうち正解だけ終わり方の形が違う … 82問 → 0
　　③ 抽象的な終わり方が正解だけ … 6問 → 0
　　② 下線部の語を含むのが正解だけ … 1問 → 0
　　① 極端な言い方（必ず・すべて・まったく）が誤答にだけある … 統計で本物と出た24肢 → 0
　　④ 「〜ではなく〜だ」が正解だけ … 統計で本物と出た16問 → 0

　合計132問。**本文・台本・設問文・正解には一字も触っていません。誤答だけの書き直しです。**
　→ **音声の作り直しは0本です。**

■ 正直な結果

　本文なしの正答率は **81.3％ → 79.9％** にしか下がりませんでした。
　いちばん下がったのは聴解の課題理解（53.3％→40.0％）です。

　つまり、**機械で拾える手がかりは、全体のごく一部でしかありませんでした。**
　残っている大きな手がかりは、機械では拾えない書き癖です。

　　・正解がいつも「認めつつ、しかし〜」という中庸・譲歩の言い方で、
　　　誤答がいつも断定・単純（読解で53問）
　　・下線部の語をそのまま開いた選択肢が1本しかない（読解で39問）
　　・聴解の概要理解で、選択肢のうち1本だけが「〜力」「〜の値打ち」のような
　　　価値の言葉で、残り3本が具体的な行為（17問）
　　・法律・行政・保険・防災・暦などの一般知識だけで決まる（読解で34問）
