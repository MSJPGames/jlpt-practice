■ 今回の変更（情報検索20問）
 ・選択肢を書き直した
     条件を照らし合わせる10問は、短すぎた肢（「区分Bのみ」「「あさひ」を購入する」）を
     どの条件をどう満たすかまで書き込んだ26～36字の文にした。
     金額を計算する10問は、4肢が全部同じ字数になっていたので、
     金額の道筋そのものを設計し直して桁を散らした。
     誤答はすべて「加算漏れ」「割引の適用漏れ」「区分の取り違え」など、
     こう間違えるとこの額になる、という道筋のある数にしてある。

 ・★ 資料（画面に出るお知らせ・料金表）の書き方を3か所直した
     いずれも「読み方によって正解が2つになる」箇所でした。
     1) 助成金の「上記の助成率にそれぞれ一割を加えます」
        → 5割に10ポイント足して6割とも、5割の1割増しで5.5割とも読め、
          どちらの金額も選択肢にありました。
          「二分の一の区分は五分の三に、三分の二の区分は五分の四になります」と明示。
     2) 一時保育の「利用は1日8時間、1か月20時間までとします」
        → 注意書きに「上限時間を超えた分は1時間900円」とあり、矛盾していました。
          「20時間を目安とし、これを超えて利用することもできます」に変更。
     3) 引っ越しの「取り消しは基本料金の半額」
        → 繁忙期の割増を加える前か後かが不明で、どちらの額も選択肢にありました。
          「加算前の基本料金の半額」と明示。
