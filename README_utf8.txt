【3】音声を作り直す
  make_n1_listening_audio.bat をダブルクリックします（N2からN5も同じ）。
  ※batファイルは、python のスクリプト（make_n1_listening_audio.py）を
  　よび出すだけの小さなファイルです。中身の仕事は py のほうがしています。
  中身が変わったものだけ作り直すしくみなので、作り直されるのは次の14本だけです。

  N1 ... audio/n1_q3_17.mp3 n1_q4_04.mp3 n1_q4_09.mp3 n1_q4_32.mp3 n1_q4_35.mp3
  N2 ... audio/n2_q4_08.mp3 n2_q4_16.mp3 n2_q4_39.mp3 n2_q4_41.mp3
  N3 ... audio/n3_q4_03.mp3 n3_q5_05.mp3
  N4 ... audio/n4_q4_09.mp3 n4_q4_16.mp3
  N5 ... audio/n5_q4_16.mp3

  もし「変更なし」ばかりで1本も作り直されないときは、上の14本を消してから
  もう一度 bat を動かしてください。

【4】できた14本のmp3を、GitHubの audio フォルダにアップロード
  HTMLと音声は、かならず一緒にアップロードしてください。
