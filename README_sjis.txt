■ 今回やったこと：出題の偏りを6つの角度から調べました

【直した①】並べかえの★の位置 ― 86問
  kijun.json に「公式の並べかえは全問3スロット目」と実測が入っています。
  サイトを数えたところ、N2・N4・N5は全問3番目でしたが、
      N1 … 154問のうち78問が2番目
      N3 … 122問のうち8問が1・2・4番目
  になっていて、公式とずれていました。
  86問を3番目にそろえました（設問の★の場所・正解・解説の★の一文を書きかえ）。
  ★語順・選択肢・文の中身は変えていません。正解は「その語順の3番目のことば」です。

【直した②】同じ設問が2回出てくるもの ― 5組
      N3 文脈規定 「今日は風もなく、（　）な天気だ」が2回
      N3 用法     【素直】が2回
      N4 表記     「あるいて」が2回
      N4 文脈規定 「この もんだいは、（　）むずかしく ありません」が2回
      N4 用法     「おと」が2回
  あとの1問を、それぞれ別の問に作り直しました
  （穏やか／引き受ける／おとうと／それほど／こわれる）。
  作り直したあと、ほかの問とぶつかっていないことをプログラムで確かめています。

【調べて、問題なしと分かったもの】
  ③ 正解の位置 … 画面で選択肢をまぜない大問（聴解・情報検索）を、
     肢の数ごとに数えました。どれも 23～34% にそろっていて偏りなし。
  ④ 聴解の場面 … N1の「そのほか」が多く出ましたが、中を見ると
     動物園・写真館・消防団・和菓子屋・銭湯・山小屋・果樹園・印刷所・
     コンサートホール・直売所…と、むしろよく散っていました。
     会社と学校ばかりに寄っている、ということはありません。
  ⑤ 読解の本文 … 1本の本文にいくつ問がついているかを数えました。
     短文1問／中文3問／長文4～6問で、公式の作りと同じです。
     本文の使い回しもありません。
  ⑥ 語彙の対象語 … 同じ語が2回出るものが、N3漢字読み46語・N3表記29語・
     N5漢字読み18語などありましたが、設問の文はそれぞれちがいます。
     同じ語をちがう文でもう一度見るのは復習になるので、直していません。
