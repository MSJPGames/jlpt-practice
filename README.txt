防災ゲーム・じしんゲームを 非公開にする
========================================

【入っているファイル】

  games.html     2つのカードを削除（あそび場から消えます）
  seikatsu.html  防災カードを削除
  sitemap.xml    2つを除外（123件）

  この3つを上書きしてください。


【サイトから消えるもの】

  ・ぼうさいクイズ（bousai_game.html）
  ・ゆれるまえに（yureru_game.html）

  どこからもリンクされなくなり、sitemap からも外れます。
  検索にも載りません。


【ファイル自体をどうするか】

  リンクを消すだけで、実質的に非公開になります。
  ただ、URLを直接入力すれば開けてしまうので、
  気になる場合は次のどちらかを。

  A. サーバーから削除する（確実）
     bousai_game.html / bousai_data.js / bousai_edit.html
     yureru_game.html / jishin_game.html / jishin_data.js
     og_bousai.png
     これらを消してください。

  B. 残しておく（作り直す可能性があるなら）
     リンクが無いので、実質見られません。


【あそび場に残るもの（7つ）】

  ひらがなラッシュ／カタカナラッシュ／もぐらたたき／
  ゴミ分別ゲーム／かなバーガー／あいうえおパネル／
  外国語 ことばクイズ／道案内ゲーム

  ★ ゴミ分別ゲームは そのまま残しています。
    10言語・出典12件の作業は無関係なので。

  ゴミ分別ゲーム 1つだけになりました。

  「これから ふやしていきます」に、じしん・大雨 も
