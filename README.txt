音読みゲーム 修正（呉音・漢音への対応）
========================================

【ご指摘】

  「明」は「めい」も「みょう」も正しいのに、
  片方しか正解と見なされていなかった。

  → そのとおりでした。バグです。修正しました。


【何が悪かったか】

  データが1字につき音読みを1つしか持っていませんでした。
  実際には呉音・漢音で2つ以上ある字が多くあります。


【直したこと】

  ■ onyomi_data.js
      ons:[{r:読み, k:呉/漢/慣, w:例語}] を追加。35字に複数読みを登録。
      on は代表読み（表の見出し用）として残してあります。

      例）明 → めい（漢・説明 せつめい）／みょう（呉・明日 みょうにち）

  ■ onyomi_game.html
      ・音読みあてモードで、その字の正しい読みならどれを選んでも正解に
      ・誤答の選択肢に、その字の別の読みが混ざらないように
        （たとえば「生」の問題で「しょう」が誤答に出ると、
          正しいのに不正解になってしまう）
      ・解説に呉音・漢音を両方、例語つきで表示

  ■ onyomi_cantonese.html（解説ページ）
      「一個字，兩個音 — 吳音同漢音」の節を新設。
      呉音・漢音がなぜ2系統あるかと、対応表7組。

  ■ onyomi_edit.html（編集ページ）
      読みの欄で複数の読みを扱えるように。書き方：

          めい 漢 説明 せつめい / みょう 呉 明日 みょうにち

      読み・種別（呉／漢／慣）・例語 を空白で区切り、
      複数は / で区切ります。1つだけなら「めい」だけでも可。
      CSVの列名も「音読み」→「読み」に変わりました。

      検証も強化：複数の読みすべてを韻尾規則にかけます
      （慣用音は対象外）。


【副産物：教える内容が増えました】

  -ng で終わる字は、呉音と漢音がきれいに対立します。

      呉音 → う（よう・おう）    漢音 → い（えい）

      明 みょう／めい　京 きょう／けい　生 しょう／せい
      經 きょう／けい　兄 きょう／けい　成 じょう／せい

  つまり「明」で「う」と「い」の両方が正しいのは偶然ではなく、
  規則です。ご指摘のおかげで、
  ゲームの穴が解説の材料になりました。


【検証したこと】

  ・110字すべての読み（複数含む）が韻尾規則に合うか照合
    → 規則から外れるものは無し（慣用音を除く）
  ・「明」に めい／みょう のどちらを選んでも正解になるか
  ・300回出題して、同じ字の別読みが選択肢に同時に出ないか
    → 0回
  ・編集ページで読みの追加・削除・規則違反の検出
  ・pageerror 0
