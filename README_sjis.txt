■ 何が起きていたか

 原因は一つです。**同じ意味群の語を4つ並べる**という作り方をしていました。

   古いデータを（　）する。       廃棄／破棄／放棄／撤去
   機械を入念に（　）する。       点検／検査／検討／点在
   他国の内政に（　）すべきでない。 干渉／介入／関与／干与

 これでは正解が1つに定まりません。「干与」は「干渉」とほぼ同義の語で、
 4肢のうち3肢が成立していました。

 直し方は決まっていて、**意味で並べるのをやめ、同じ漢字を含む別語・
 音の近い語に寄せる**ことです。

   廃棄 ← 排気（音は同じ、意味は別）
   点検 ← 検索
   干渉 ← 侵入・関連・干拓
   実態 ← 生態・容態・事態
   訂正 ← 改正・更正・矯正
