【聴解 もんだい6「音声の特徴」18問 書き直し】

■ 何を直したか
　40問を調べたところ、練習の軸がかたよっていました。
　　・聞き分け12問 … 音の対立が「長音・促音・撥音」の3種類だけ。
　　　　　　　　　　　語頭が「し／しゅ／しょ」の問題が12問中7問。
　　・書き戻し12問・応答16問 … 縮約形が「～とく」に集中（4問続き・6問続き）。
　　　　　　　　　　　応答の型も「完了報告→感謝」「予告→お願いします」の2つだけ。
　　音を聞かなくても選択肢の形だけで解けてしまう問題がありました。

　18問を新しい軸で作り直しました。
　　・聞き分け6問 … 清音と濁音／拗音の有無／母音の質（各2問）
　　　　　　　　　　6問とも、正解をふせると4本すべてが文にあてはまります
　　　　　　　　　　（＝音を聞かないと決められない）。
　　・書き戻し5問 … ～んない／～じゃう／文末の伝聞「って」／～なくちゃ／～とけば
　　・応答7問 … 聞き返す／なだめる／訂正する／条件をつける／わびて約束する／
　　　　　　　　依頼を受ける／言い返す（7問とも別の型）
