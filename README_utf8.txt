N2 選択肢の長さを公式に合わせました（★N2の×もゼロになりました）

【入っているもの】
  n2_quiz.html だけです。GitHub の同じ名前のファイルに上書きしてください。
  音声（mp3）は変わっていません。問数も変わっていません（3,484問のまま）。

【直したところ】
  公式問題集と市販2種の実測に対して、選択肢の長さがずれていた7か所を直しました。

  ・漢字読み（1,596問）
      4つの読みが全部同じ字数にそろっていました（長短差0.02字／公式0.8字）。
      **まちがいの肢だけ**を1つ選び、促音「っ」や長音「う」を落とす／足す形に直しました
      （「しゅっぱん」に対する「しゅぱん」のような、長音・促音の聞き分けを問うまちがい）。
      1,273問を直して長短差0.8字。**正解の読みには一切さわっていません。**
  ・言い換え類義（172問）… 肢5.5字→3.5字（公式3.7字）。長い言い回しを1語に。
  ・文脈規定（311問）… 長短差1.0字→0.8字（公式0.4〜0.8字）。まちがいの肢を正解と同じ長さの語に。
  ・用法（156問）… 長短差3.4字→6.0字（公式4.2〜7.9字）。例文の長さにばらつきを付けました。
  ・文の文法1（288問）… 肢4.3字→5.2字（公式5.5字）。助詞1つの肢を文型のかたまりに。
  ・文の文法2（120問）… 肢4.9字→4.3字・長短差3.4字→3.2字（公式3.9字・2.7字）。
      前回足した72問が長すぎたので、そこだけ短くしました。
  ・文章の文法（80問）… 肢3.6字→5.0字・長短差1.1字→1.8字（公式5.9字・2.1字）。

  ★どの大問も **設問文（question）は1字も変えていません**。**正解の位置も変えていません**。
  ★カタカナ語が正解の2問（オートメーション／レクリェーション）は、
    正解を変えないと条件に入らないため、**直さずそのまま残しました**。

【確かめたこと】
  ・kijun_check（公式問題集と市販2種の実測との突き合わせ）
      **N2の×はゼロになりました**（文字・語彙／文法／読解／聴解のすべて）。
      「長さで正解が当てられる作り」「正解の位置の偏り」もありません。
  ・ブラウザで全問を実際に描画（幅390pxと900px）
      N2 3,484問、エラー0・表示くずれ0・問数表示のずれ0。並べかえの採点も実際に動かして確認。
