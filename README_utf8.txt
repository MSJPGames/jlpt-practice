　これで聴解の重複しらべ（59組）は全部おわりです。

■ もんだい2「ポイント理解」7問

　40問を読み比べたところ、同じ運びの問題が6組ありました。
　　・「お金は足りている、足りないのは当日動く人手」が2問（正解の文言まで同じ）
　　・「待遇・体調・多忙・人間関係を全部否定して、前向きな信念で辞める」が2問
　　・「時間・資料・練習量・体調を全部否定して、自分の進め方に帰す」が2問
　　・「資格・年数・敬語・味・宣伝を退けて、正直さ・素直さに落とす」が3問

　もっと深いのは誤答の作り方でした。ほとんどの問題が
　　もっともらしい表面的な理由（お金・天気・体調・忙しさ・人間関係）を三枚並べて潰し、
　　正解は内面や、人の気持ち、小さな行き違いに落とす
　という同じ形で、会話を聞かずに「いちばん内面的な肢」を選ぶだけで解けていました。

　7問を、それぞれ別の山場で作り直しました。
　　数の取り違え／きっかけを答える／場所と動線／気づけないことが問題／
　　時期が早すぎた／続けられる条件／引き際を学んだ

　あわせて
　　・展開が「三振型」（順に否定して最後に独白）だった7問を2問に
　　・正解がふつうに予想される答えである問題を0問から4問に
　　・誤答4本を同じカテゴリーにそろえ、型で切れないようにした

■ もんだい6「音声の特徴」6問

　先に18問を書き直しましたが、残っていた6問です。
　　・聞き分け3問 … 子音の対立（さ行とた行／か行とた行）、語末の一拍のちがい
　　　　（これまでは長音・促音・撥音の有無だけで、ほかの軸がありませんでした）
　　・書き戻し2問 … 「〜ちゃ／〜じゃ（＝〜ては／〜では）」「〜てく（＝〜ていく）」
　　　　（これまでは「〜とく」に6問も集中していました）
　　・応答1問 … 言いさし（「〜んですけど…」）を引き取る

　聞き分けの3問は、正解の語をふせて4本とも文の枠に入ることを確かめました
　（1本しか入らないと、音を聞かなくても解けてしまいます）。
　4本の拍数もそろえ、語末や語頭が重なるようにして、音でしか切れないようにしました。
