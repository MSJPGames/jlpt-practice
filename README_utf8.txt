【聴解 もんだい1「課題理解」25問 書き直し】

■ 何を直したか
　54問を全部読み比べたところ、同じ仕掛けの問題が16組・25問ありました。
　いちばん深い重なりは誤答の作り方で、ほとんどの問題が
　　①他の人がやること　②後でよいこと　③すでに済んだこと
　という同じ三枚組でできていました。仕掛けのほうも
　　・前提の手続きが済んでいないと先に進めない … 8問
　　・必要な数や返事が分からないと動けない … 4問
　　・窓口が◯時までだから今から行く … 4問
　に固まっていて、台本を最後まで聞かなくても当たりがつく状態でした。

　25問を、それぞれ別の仕掛けで作り直しました（待ち時間の長い作業を先に始める／
　数えたら足りていた／天気で案が決まる／分担の交換／道具の故障でやり方を変える／
　途中だった作業を再開する／予算の残りで買う物が変わる／人手が増える／
　早く帰る人に先に渡す／一人になって一つ捨てる／客に選んでもらう／
　似た二つの物を現物で確かめる／締め切りの例外を認める／条件を変えて頼み直す／
　傷むので置き場を移す／前の人の記録を先に読む／資格のある人を呼ぶ／
　紙と実際が食い違う／予約の重なりをずらす／代わりの材料で試す／
　集荷に間に合わせる／車いすの要望で会場を作り替える／積む順を入れ替える　ほか）。

■ ついでに直した大きな穴（全体に効きます）
　複数選ぶ型（「アとエ」のように2つ・3つ選ぶ問題）で、
　**選択肢に出てくる記号を数えるだけで正解が当たる**ことが分かりました。
　もんだい1の6問のうち5問がこれに当たっていました。
　　例：ウ3回・エ3回・カ3回／ア・イ・オ各1回 → 多い順に3つ取ると正解
　4本の選択肢に出てくる記号を「2n種類・どれもちょうど2回ずつ」にそろえると、
　この数え方も、合計点の数え方も、消去法も同時に効かなくなります。
　6問ともこの形に直しました（うち4問は台本を一字も変えていないので、
　音声の作り直しは起きません）。

■ 確かめたこと
　・二重正解 0件（正解をふせて別の担当が5回解き直し、5回とも全問一致）
　・音声にしたときに読みが割れる語 0か所（「十分」「一日」「柄」「粉」など71か所を修正）
　・全5468問がエラーなしで「正解」判定
　・「課題理解」54問の正解のかたより … 最長25.0％／最短25.0％
　・サイト全体5468問 … 最長25.2％／最短25.3％
　・答えるのが女の人の問題 3問 → 12問、発話の回数 全問8回 → 6回7問／7回8問／8回10問
　・最後の一言で順番がひっくり返る問題 0問 → 5問
