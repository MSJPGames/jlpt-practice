① とじても結果画面に戻らない → 直しました
────────────────────────────────────────

  【本当の原因】

  「とじる」を足したこと自体は正しかったのですが、
  もっと深いところに原因がありました。

  クイズモードの終了処理が、こうなっていました。

      function quizResult(){
        … 結果画面の中身を組み立てる …
        openSign(G.city);     ← 結果画面を表示せずに貼り紙だけ開く
      }

  結果画面は「中身を作るだけ」で、表示されていませんでした。
  だから貼り紙を閉じても、戻る先が存在しませんでした。

  【直した内容】

  ・クイズ終了時に、結果画面を表示してから貼り紙を開くようにしました
    → 貼り紙を閉じると、下に結果画面が残っています

  ・貼り紙・ことば・出典の各シートは、
    「とじる」でも背景タップでも、結果画面に戻ります

  ・ゲームの途中で開いたときは、これまでどおり
    結果画面は出ません（戻り先が無いので）

  結果画面には次の4つが並びます。
      🔁 もう一度
      🧾 貼り紙を もう一度 読む
      📚 もとにした しりょう
      🗺️ 別の街をえらぶ

② ベトナム語が古いままの件
────────────────────────────────────────

  Rác cháy được のまま ＝ gomi_data.js が反映されていません。
  順に試してください。

  1. 強制再読みこみ
       Windows … Ctrl + F5
       Mac     … Cmd + Shift + R
     これで直ることが多いです（ブラウザが古いJSを覚えているため）。

  2. それでも変わらないとき、ファイルを直接見る
     ブラウザで次を開いてください。

       https://msjpgames.github.io/jlpt-practice/gomi_data.js

     Ctrl+F で「Rác thông thường」を検索します。
       見つかる   → ファイルは新しい。1のキャッシュ問題です
       見つからない → アップロードが反映されていません

  3. GitHub 側の反映待ち
     GitHub Pages は反映に数分かかることがあります。
     少し時間をおいてから、もう一度 Ctrl+F5 を。

確認していただきたいこと
────────────────────────────────────────

  ・クイズを1回終える → 貼り紙が出る →「とじる」
    → 結果画面が見えて、「もう一度」が押せるか

  ・🌐 → Tiếng Việt で Rác thông thường になったか


【検証したこと】

  ・クイズ終了 → 貼り紙 → とじる → 結果画面（ボタン4つ）
  ・結果画面 → 貼り紙 → 背景タップ → 結果画面
  ・結果画面 → 出典 → とじる → 結果画面
  ・読解クイズ完走 → ことば画面 → とじる → 結果画面
  ・もう一度 → ゲーム再開、結果画面は消える
  ・生活型のゲームオーバーでも結果画面が正しく出る
  ・ゲーム中に開いた場合は結果画面を出さない
  ・pageerror 0
