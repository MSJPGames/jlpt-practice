【聴解 もんだい3「概要理解」19問 書き直し】

■ 何を直したか
　56問を全部読み比べたところ、話の組み立て方が三つの型に固まっていました。
　　・「うちには◯◯が二つあります」型 … 45〜49の五問が連続。
　　　しかも五問とも結論が「どちらか一方ではない、両方要る」。
　　　三問目からは、台本を聞かずに「両方が要る」と書いてある肢を選べば当たる。
　　・「三つ挙げてみます」型 … 50〜54の五問が連続。
　　　誤答が全問「三つの事例のうち一つをそのまま取り出したもの」なので、
　　　事例を一つ選んだ肢を捨てるだけで正解に届く。
　　・「通説を退ける」型 … 残りのほとんど。
　　　誤答の三枚も、ほぼ全問が「退けた通説」＋「本文中の具体例」二枚。

　19問を、それぞれ別の組み立てで作り直しました。
　　体験談（出来事を順に語り最後に意味づけ）／数字の読み替え／
　　聞き手への依頼で終わる／人の一言を引いて答える／例外を挙げて原則を言い直す／
　　自分の失敗と、そこから作った基準／問いを立てて予想を二つ退ける／
　　やめることの提案／たとえ一本で押し通す／誤解の先回り／順序の入れ替え／
　　条件つきの賛成／二つ比べて片方を捨てる

　あわせて
　　・逆接（「しかし」「ですが」）を使わずに結論に至る問題を 3問 → 14問
　　・くだけた話し方の問題を 0問 → 5問、聞き手を置く形を 0問 → 4問
　　・冒頭が「一つ申し上げます／お願いを一つ」で始まる問題を 6問 → 1問
　　・選択肢4本の終わり方の形をそろえた（正解だけ動詞で言い切り、という
　　　形の手がかりが9問にあったのを 0問に）

■ 確かめたこと
　・二重正解 0件（正解をふせて別の担当が4回解き直し、4回とも全問一致）
　・音声にしたときに読みが割れる語 0か所
　・全5468問がエラーなしで「正解」判定
　・「概要理解」56問の正解のかたより … 最長25.0％／最短25.0％
　・サイト全体5468問 … 最長25.2％／最短25.3％
