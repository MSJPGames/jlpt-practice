今回の中身

聴解に「音声の特徴」という練習コーナーを足しました。本試験にはない形式で、
話し言葉の音の変化に慣れるためのものです。3段階になっています。

  1. 聞き分け  12問 … 長音・促音・撥音のあるなしを聞き分ける（4択）
  2. 書き戻し  12問 … 縮約形を聞いて、縮約しない形に戻す（4択）
  3. 応答      16問 … 縮約形を含む発話に、いちばんよい返事を選ぶ（3択）

聴解 221問 → 261問。サイト全体 5,184問 → 5,224問。

聴解のメニューのいちばん下に「音声の特徴」というボタンが増えています。
