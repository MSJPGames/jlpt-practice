ゲームオーバー時に説明が隠れる件 → 直しました
========================================

【入っているファイル】

  gomi_rush.html   これ1つだけ。上書きしてください。
  （gomi_data.js は変更なし。前回のままで大丈夫です）


────────────────────────────────────────
ご指摘の件
────────────────────────────────────────

  「ゲームオーバーの画面の下に出てしまって、
    ゲームを再開しないと見ることができません」

  そのとおりでした。私の直し方が原因です。

  説明パネルを出したあとに ミスを数えていたため、
  それが5回目だとゲームオーバー画面が上に重なり、
  パネルが下に隠れていました。

  ★ いちばん大事な「最後の1回」の説明が見えない、
    という最悪の順序になっていました。


【直した内容】

  順序を入れかえ、先にミスを数えるようにしました。

    ゲームオーバーでない → これまでどおりパネルを出す
    ゲームオーバー       → 結果画面の中に、赤い枠で説明を出す

  結果画面ではこう出ます。

    🔥 あぶない！
    割れたガラスのコップ を「そのまま袋へ」はいけません。
    袋がやぶれて、集める人がけがをします。紙に包んで「キケン」と書きます。
    ⚠️ この出し方は、ごみ収集車やごみ処理場の火事・けがにつながります。
    ─────
    📗 ヒント
    取り逃し・分別ミスが5回になりました。…

  ゲームが終わっても、危険の説明だけは必ず目に入ります。


────────────────────────────────────────
★ もう1つ、抜けが見つかりました
────────────────────────────────────────

  前回私が直したのは「処理のまちがい」の経路だけでした。

  箱をまちがえたとき も、危険品目なのに
  ポップアップ（🔥 火が出る！）だけで説明がありませんでした。

  モバイルバッテリーを普通ごみに入れる——
  これはこのゲームでいちばん教えたい場面です。

  こちらも説明が出るようにしました。

    🔥 あぶない！
    モバイルバッテリー は「普通ごみ」ではありません。
    リチウムイオン電池が入っています。つぶれると激しく発火し、
    ごみの火事の原因でいちばん多いものです。
    ふつうのごみには絶対に入れません。


【あわせて】

  ゲーム開始時に、前回の結果画面と説明パネルを
  確実に消すようにしました。持ち越しを防ぐためです。


────────────────────────────────────────
確認していただきたいこと（生活型で）
────────────────────────────────────────

  ① モバイルバッテリーを わざと普通のゴミ袋に入れる
     → 説明パネルが出るか

  ② ミスを5回して ゲームオーバーにする
     （5回目を 危険なもの のまちがいにしてください）
     → 結果画面の上のほうに 赤い枠で説明が出るか

  ③ ふつうのミス（新聞紙など）
     → パネルが出ず、流れが止まらないか


────────────────────────────────────────
検証したこと
────────────────────────────────────────

  ・1回目の危険ミス → パネルが出る／時間が止まる
  ・5回目の危険ミス → パネルは出ず、結果画面に説明が載る
  ・箱のまちがい（危険品目）→ 説明が出る
  ・危険でないミス → パネルなし・流れも止まらない
  ・再開時に持ち越さない
  ・選択式はこれまでどおり
  ・pageerror 0
