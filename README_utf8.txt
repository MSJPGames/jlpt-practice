N4 聴解の音声を作る（はじめて作ります）

【今回のこと】
  N4に聴解を新しく入れました。84問ぶん、84本の音声を作ります。
  30分～1時間くらいかかります（1本あたり30～60秒）。

  もんだい1 課題理解    24問  n4_q1_01 ～ n4_q1_24
  もんだい2 ポイント理解 21問  n4_q2_01 ～ n4_q2_21
  もんだい3 発話表現    15問  n4_q3_01 ～ n4_q3_15
  もんだい4 即時応答    24問  n4_q4_01 ～ n4_q4_24

  ★もんだい3・4は、選択肢を音声で読みます（本試験と同じ）。
    画面には番号だけが出ます。

【要るもの】
  Python 3 と edge-tts（.bat が自動で入れます）
  同じフォルダに次の3つ：
    make_n4_listening_audio.py
    n4_listening_manifest.json
    file_to_daimon.json

【やりかた】
  1) この3つを「JLPT PRACTICE」フォルダに置く
  2) make_n4_listening_audio.bat をダブルクリック
  3) 待つ
  4) audio フォルダの n4_q*.mp3 を、HTMLと同じ場所に置いてGitHubへ

  途中で止めても大丈夫です。もう一度実行すれば、できていないぶんだけ作ります。

【確かめること】
  ・ログの最後が failed 0 になっていること
  ・audio フォルダの n4_q*.mp3 が 84本あること
  ・どのファイルも 144バイトの倍数であること（壊れたmp3は倍数になりません）

【間（ま）の長さについて】
  間の長さは N1～N5 で共通です。
  公式CDを実測したN2とN3を突き合わせたところ、ちがいは最大0.2秒しかありませんでした。
  級による差は測定のばらつきの範囲なので、級で分けないことにしました（2026-08-16）。
  くわしくは n4_audio_timing.json をご覧ください。
