用廣東話讀日文音讀広東語で日本語の音読みを読む

廣東話保留咗入聲。所以你一睇個粵音，就估到日文個音讀係「っ」、「ん」定係長音。呢樣嘢，講普通話嘅人做唔到。 広東語には入声が残っています。だから広東語の音を見れば、日本語の音読みが「っ」になるか「ん」になるか長音になるかが予測できます。これは普通話の話者にはできません。

好多人學日文漢字，都係一個一個死記。但係如果你識廣東話，其實你已經有一套現成嘅工具，只係冇人話過你知。 日本語の漢字を、一つずつ丸暗記している人は多いと思います。でも広東語ができるなら、すでに道具は手元にあります。誰も教えてくれなかっただけです。

一句講晒：廣東話字尾係 -p / -t / -k，日文就會出現「っ」；係 -m / -n，就係「ん」；係 -ng，就係長音。 要点：広東語の語末が -p / -t / -k なら日本語では「っ」が出る。-m / -n なら「ん」。-ng なら長音になります。

點解廣東話有著數なぜ広東語が有利なのか

日文嘅音讀，係一千幾年前由中國傳入日本嘅。當時嘅中文有「入聲」──即係字尾收 -p、-t、-k，好似「學」hok6 個 k 音咁，喉嚨會停一停。 日本語の音読みは、千数百年前に中国から日本に入った音です。当時の中国語には入声がありました。語末が -p、-t、-k で終わる音、つまり「學」hok6 の k のように、喉が一度止まる音です。

普通話後來冇晒呢啲收音，所以「學 xué」聽落係開放音，乜線索都冇。但係廣東話原封不動保留咗，所以你講「學」嘅時候，個 -k 仲喺度。 普通話ではこの韻尾が消えました。だから「學 xué」からは何の手がかりも得られません。広東語はそのまま保っているので、「學」と言うとき -k がまだ残っています。

而日文嘅促音「っ」，正正就係嗰個停頓。你唔使學點樣發「がっこう」個「っ」──你講「學」嘅時候，一直都喺度發緊。 そして日本語の促音「っ」は、まさにその止まりです。「がっこう」の「っ」を新しく覚える必要はありません。「學」と言うたびに、ずっと発音しています。

講普通話嘅人睇到普通話話者に見えるもの

學 xué　三 sān　東 dōng
三個字尾都唔同，但係同日文冇明顯關係。要逐個記。語末はそれぞれ違うが、日本語との対応が見えない。一つずつ覚えるしかない。

最緊要嘅一條：-m / -n 係「ん」，-ng 係長音。好多學生成日搞錯「東京」讀「とんきょん」定「とうきょう」──其實 東 dung1 同 京 ging1 都係 -ng，所以兩個都係長音：とうきょう。 最重要な一点：-m / -n は「ん」、-ng は長音です。「東京」を「とんきょん」としてしまう間違いが多いですが、東 dung1 も 京 ging1 も -ng なので、どちらも長音になり とうきょう です。

點樣估到「っ」「っ」をどう予測するか

收 -p / -t / -k 嘅字，如果後面接住嘅字係清音（か・さ・た・は行），個尾音就會變成「っ」。 -p / -t / -k で終わる字のうしろに、清音（か・さ・た・は行）が来ると、その末尾が「っ」に変わります。

另外，日本漢字有啲同繁體字唔同形，要留意：學→学、國→国、發→発、實→実、萬→万、點→点、廣→広、藝→芸。意思一樣，寫法唔同。 また、日本の漢字は繁体字と形が違うものがあります：學→学、國→国、發→発、實→実、萬→万、點→点、廣→広、藝→芸。意味は同じで字体が違うだけです。
