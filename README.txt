日文助詞（中国語話者向け）
====================================

【入っているファイル】

  chinese_joshi.html   「日文助詞 — 中文母語者最難嘅一關」（新規）
  og_joshi.png         SNS用のカード画像（1200×630）
  chinese_start.html   入口ページ（導線を1つ追加・上書き）
  langdata.js          多言語データ（4言語に登録・上書き）

  すべて jlpt-practice フォルダの中（htmlと同じ場所）に置いてください。
  画像も同じ場所です。


【なぜ助詞か】

  入口ページで「中国語がまったく助けにならない三つ」の筆頭に
  助詞を挙げましたが、その先がありませんでした。
  中国語話者の検索需要が最も大きいのもここです。


【中身】

  一、なぜ難しいか（中国語は語順、日本語は助詞）
  二、基本の七つ（は・が・を・に・で・と・の）
  三、は と が（新情報がどちら側にあるか）
  四、中国語話者に特有の落とし穴  ← ここが中心
        ①「的」＝「の」ではない（赤いの車 ✕）
        ②「在」が に と で に分かれる
        ③ は は「是」ではない
        ④「和」は と とは限らない（と / や）
        ⑤ 助詞を落とさない
  五、練習10問（8問ランダム出題）

  ④は日本人向けの文法解説には書かれていない内容です。
  中国語話者にしか起きない間違いなので。


【つくりながら直したこと】

  最初、日本語の例文に繁体字を使っていました
  （學生です／圖書館で 勉強します）。
  日本語としては誤りなので、新字体に直しました
  （学生です／図書館で 勉強します）。
