  漢字読み7357問はすでに直してあるので、これで**文字・語彙13525問すべて**が
  「まちがいの3つがなぜだめか」を書いた解説になりました。

  大問ごとに、書くことを決めてあります。
    ・表記  … まちがいの漢字が**どう読むか／どんな意味か**（「走」は「はし（る）」など）。
              その組み合わせでは日本語のことばにならない場合はそう書く。
    ・語形成 … その接辞が**何につくか／何を表すか**（「無」は～がない、「不」は～でない、
              「未」はまだ～していない、「非」は～ではない、のような使い分け）。
    ・言い換え類義 … 下線部の語と正解の語の**重なる意味**を示し、
              まちがいの語は意味を示したうえで「意味が逆」「対象がちがう」などを書く。
    ・用法  … まちがいの文から**まちがっている部分だけを引いて**、
              その場面では**どんな語を使うのが正しいか**を書く。
    ・文脈規定 … 正解の語が**文のどの部分と結びつくか**を示し、
              まちがいの語は意味と、なぜこの文に入らないかを書く。

  どの解説も、まちがいの肢を**「」でことばを引いて**指します（番号では呼びません）。
  画面では選択肢が並べ替わるので、番号だと表示とずれるためです。
