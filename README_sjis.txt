【本文なしで解けてしまう問題 ― 第一段と第二段（178問）】

■ やったこと

　第一段：機械で拾える手がかりを全部つぶした（132問）
　　⑥同じ本文の別の設問が答えを漏らす19問／⑤正解だけ終わり方の形が違う82問／
　　③抽象的な終わり方が正解だけ6問／②下線部の語を含むのが正解だけ1問／
　　①極端な言い方が誤答にだけある24肢／④「～ではなく～だ」が正解だけ16問
　　→ すべて0件に。

　第二段：残っていた ①39問・④7問（統計では弱いが、1問ずつ見れば使える手がかり）
　　→ すべて0件に。

　第三段：いちばん悪かった「内容理解（中文）」85問の誤答を作り直した
　　（下線部の言い換えを2本以上に／別の設問から分かる肢をなくす／4肢の抽象度をそろえる／
　　　対立ペア＋的外れ2本の構図をやめる／控えめな言い方を誤答にも使う）
　　→ 誤答137本を書き直し。

　**本文・台本・設問文・正解には一字も触っていません。誤答だけの書き直しです。**
　→ **音声の作り直しは0本です。**

■ 正直な結果

　　本文なしの正答率（サイト全体）　81.3％ → 79.9％
　　内容理解（中文）だけを取ると　　97.5％ → 95.0％

　誤答を137本も書き直して2.5ポイントです。**この方向では、これ以上は下がりません。**

　理由は、四択という形そのものにあります。設問に対してきちんと噛み合う肢は
　本来ひとつだけなので、日本語と論理に強い読み手であれば、本文がなくても
　「噛み合っている一本」を見つけられてしまいます。

■ ここで測るべきもの

　いま比べる相手がありません。**公式問題集が、同じテストで何％になるのかが分かっていません。**
　（ベンチマークを作ったとき、著作権に配慮して公式の設問文・選択肢の文言を
　　一切書き写さなかったため、同じ実験ができません。）

　公式が同じ条件で85～90％なら、これは四択という形の性質であって、
　当サイトの欠陥ではありません。逆に公式が40％台なら、まだ直す余地があります。
　**この一点を確かめないまま、これ以上ここに手をかけるのは、
　　105問のたまたまのブレに合わせにいった前回と同じ失敗になります。**
