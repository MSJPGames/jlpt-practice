■ 何をしたか

  聴解297問を「話の組み立て方（展開型）」で全数分類したところ、強い偏りがありました。

    問題1（課題理解）46問 … 条件つき先行 50.0%／不在・締切 28.3% に集中
                            提案の撤回 6.5%／分担の誤解 2.2%／表面的理由の否定 0%
    問題3（概要理解）40問 … 問題提起と再定義が 90.0%
                            残り4種類のうち3種類が 0%

  問題3は36問すべてが同じ骨格で、最終文が「XではなくY」という言い換えに着地していました。
  分類した担当がこう書いています。

    「D11一択の展開だと、誤答も『否定された旧説』『具体例の語句拾い』『譲歩で認めた点』に
      自動的に決まってしまうため、展開型の偏りが誤答型の単調さを直接引き起こしています。」

  そこで、足りない型だけを24問足しました。

    問題1  46問 → 54問（提案の撤回3・分担の誤解3・表面的理由の否定2）
    問題3  40問 → 56問（一般論から主張へ4・対比5・具体例の積み上げ5・譲歩からの転換2）

  結果

    問題1 … 条件つき先行 42.6%／不在・締切 24.1%／複数条件 11.1%／提案の撤回 11.1%
            分担の誤解 7.4%／表面的理由の否定 3.7%
    問題3 … 問題提起と再定義 64.3%／譲歩 10.7%／対比 8.9%／具体例 8.9%／一般論 7.1%

  聴解  273問 → 297問
  全体 5,380問 → 5,404問


■ 点検したこと

  ・答えを伏せて解き直す点検を3周おこないました（二重正解・正解なしは最終的に0件）
  ・そのつど「誤答3本が別々の理由で落ちるか」を見て、同じ落ち方に偏った肢を作り直しました
     1周目 … 問題3の具体例型で、誤答3本がそのまま「並べた3つの例」になっていた（4問）
     2周目 … 対比型で、誤答3本がどれも「片側の描写」になっていた（3問）
     3周目 … 台本に無い方向のつもりで作った誤答が、正解の上位概念になっていた（1問。二重正解）
  ・全5,404問を1問ずつ画面に出して正解を選ぶ通し検査 … 5404/5404、不具合なし
  ・最長肢正解率／最短肢正解率

       問題1  25.0% / 25.0%
       問題2  25.0% / 25.0%
       問題3  25.0% / 25.0%
       問題4  34.4% / 32.8%   ← 3択なので 33.3% が中立。手を入れていません
       問題5  25.0% / 25.0%
       音声の特徴 27.5% / 27.5%

■ 今回わかったこと（次に生かすこと）

  ・展開型の偏りは、そのまま誤答型の単調さになる。台本の骨格を変えないと誤答は変えられない
  ・「話題として自然だが台本が触れていない」誤答を作るとき、それが正解の上位概念になっていないか
    を必ず確かめること。上位概念は落ちない（二重正解になる）
  ・細部の数値をずらす誤答（三十分→一時間）は、概要理解では使わないこと。
    数字を覚えている前提の大問ではないので、誤答として働かない
