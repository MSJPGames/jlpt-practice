【作問の基準と検査の道具（N2～N5でもそのまま使う）】

■ 使う順番（この順を守ってください）

　1. 公式問題集 N◯ を分析して kijun.json の "N◯" を埋める
　　　このとき "_未確認" の項目も全部埋めること
　2. kijun_check.py を、いまの n◯_quiz.html に通す
　　　→ どこがどれだけずれているかの一覧が出る
　3. ずれの大きい大問から着手する
　　　★作問の条件（字数・発話数・選択肢の長さ）は kijun.json から写すこと
　　　★既存データの min/max を条件にしてはいけません。いまのズレをそのまま固定してしまいます
　4. 書き手と、正解をふせて解く人を、OKが出るまでくり返す
　5. yomi.py が 0か所 → blindtest.py が 40％以下 → kijun_check.py が全部◯ → 納品

■ 入っているもの

　kijun.json ……… 公式問題集から取った合格ライン。N1は実測ずみ、N2～N5は空欄
　　　　　　　　　値は [公式の平均, 許容の下, 許容の上]
　　　　　　　　　"_未確認" ＝ 公式を見ないと分からないこと（音声の読み上げの順序など）

　kijun_check.py … 完成した html を丸ごと測って、公式基準との合否表を出す
　　　　　　　　　python3 kijun_check.py n1_quiz.html N1
　　　　　　　　　◯以外が一つでもあれば納品しない

　yomi.py ……… 音声合成で読みが割れる語を洗い出す（台本を出す前に必ず）
　　　　　　　　　python3 yomi.py out.json --all
　　　　　　　　　「十分」「一日」「一人」「柄」「面」「札」「粉」「空く」などを見つけます

　blindtest.py … 本文や台本を見せずに解かせて、当たってしまう率を測る
　　　　　　　　　python3 blindtest.py make n1_quiz.html 主張理解（長文） 40
　　　　　　　　　python3 blindtest.py score blind_key.json blind_out.json
　　　　　　　　　25％（3択は33％）に近いほど健全。40％を超えたら作り直し

■ いまのN1を kijun_check.py に通すと

　まだ×が残っています。
　　課題理解 … 発話数 7.5回（公式10.3）
　　概要理解 … 選択肢12.2字（公式9.1）／肢の長短差3.7字（公式1.8）／同性ペア4問（公式0問）
　　読解 …… 最長肢正解率24.8％（公式12.8）／最短肢正解率24.8％（公式32.3）
　　文字語彙 … 最長肢正解率25.3％（公式16.9）

　読解と文字語彙は、公式が「短い肢のほうが正解になりやすい」作りなのに対して、
　当サイトは25％ちょうどにそろえてあります。均等が正しいという思い込みでした。
