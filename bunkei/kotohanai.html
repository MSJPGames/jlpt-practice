NIHONGO NO HEYA
〜ことはない
there is no need to ~
N3 助言・忠告
意味
助言・忠告「〜する必要はない」
全面否定「〜する可能性はない」
その行為をしなければいけないのではないか、と心配している相手に、「その必要はありませんよ」と安心させたり、助言したりする言い方です。必ず理由や根拠といっしょに使われます。「何も〜ことはない」「わざわざ〜ことはない」の形でよく使います。
コアイメージ
理由とセットで使うのがこの文型のポイントです。理由がないと、ただ突きはなしたように聞こえます。
接続
［動詞 辞書形］＋ ことはない
ていねいに言うときは「〜ことはありません」。話しことばでは「〜ことないよ」も使います。
いっしょに使うことば
いっしょに使う語
何もわざわざそんなに別に今から
例文
ことはない
まだ時間があるから、そんなに急ぐことはないよ。
There is still time, so there is no need to hurry like that.
何も〜ことはない
何もそこまで謝ることはないと思うけど。
I do not think you need to apologize that much.
わざわざ〜ことはない
家にあるんだから、わざわざ買うことはない。
We have it at home, so there is no need to go out and buy one.
ことはありません
初めての人ばかりですから、心配することはありません。
Everyone here is new, so there is nothing to worry about.
全面否定
あの人が約束を忘れることはない。いつも確実だ。
There is no chance that he forgets a promise. He is always reliable.
ほかの用法
①可能性がまったくないと言う
「〜する可能性はない」「〜とは考えられない」という全面否定の意味になります。助言の用法とちがって、相手の心配をやわらげる場面とはかぎりません。
この橋は新しいので、こわれることはない。
②「〜たことはない」との区別
た形につくと経験の「〜たことがある」の否定になり、まったく別の意味です。辞書形につくかた形につくかで見分けます。
わたしは北海道へ行ったことはない。　→ 経験がない
にた文型とのちがい
〜なくてもいい
どちらも「必要がない」ですが、言う場面がちがいます。「ことはない」は相手が心配しているときに使い、気持ちをやわらげるはたらきがあります。
〜ことはない〜なくてもいい
場面相手が心配している事実として必要がない
気持ち安心させる・助言中立的
ていねいさ目上には使いにくいふつうに使える
○ そんなに心配することはないよ。　→ 心配している人に
○ あしたは来なくてもいいです。　→ ただの事実
〜ことがない
一字ちがいですが、「は」があるかないかで意味が変わります。「ことがない」は経験や頻度を表します。
○ 急ぐことはない。　→ 急ぐ必要はない
○ 彼が遅れることがない。　→ 遅れるということが起きない
ほかのことばで
EN
Tells someone worrying about something that there is no need to do it.
中文
用不着……；不必……；沒有必要……
