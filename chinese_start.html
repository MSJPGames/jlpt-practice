一、你已經識咗好多字一、すでに多くの語を知っている

日文有大量詞語同中文完全一樣，意思都一樣。你唔使學，一睇就明。 日本語には、中国語とまったく同じ形で意味も同じ語が大量にあります。学ばなくても見れば分かります。

呢個唔係小優勢。歐美嘅學習者要一個一個記，你係直接跳過。 これは小さな利点ではありません。欧米の学習者が一つずつ覚える部分を、丸ごと飛ばせます。

二、音讀有規律，估得到二、音読みは規則で予測できる

日文漢字嘅「音讀」，係一千幾年前由中國傳過去嘅。所以同中文有系統性嘅對應。 日本語の漢字の「音読み」は、千数百年前に中国から伝わった音です。だから中国語と体系的に対応しています。

如果你講廣東話，優勢仲大。廣東話保留咗入聲（-p / -t / -k），所以你睇個粵音就估到日文個「っ」、「ん」定係長音。學 hok → がく（がっこう）、三 saam → さん、東 dung → とう。普通話冇晒呢啲收音，做唔到。 広東語話者なら、利点はさらに大きくなります。広東語には入声（-p / -t / -k）が残っているので、粤音を見れば日本語の「っ」「ん」長音が予測できます。學 hok → がく（がっこう）、三 saam → さん、東 dung → とう。普通話ではこの韻尾が失われていて、これができません。

三、但係字形變咗三、ただし字体が変わっている

日文用嘅係新字體，同繁體唔同，亦唔等於大陸嘅簡體字。 日本語で使うのは新字体で、繁体字とも違い、中国の簡体字とも同じではありません。

上面一半「同」、一半「唔同」。所以唔可以當成簡體字嚟估——啱一半，錯一半。要當佢係第三套字。 上の表は半分が「同じ」、半分が「ちがう」です。だから簡体字として推測すると半分外れます。第三の字体だと考えてください。

四、最危險：同形異義四、最も危ないのは同形異義語

呢度先係中文母語者真正嘅陷阱。字一模一樣，意思完全唔同——而且因為你「睇得明」，所以唔會查字典。 中国語話者にとって本当の落とし穴はここです。字がまったく同じで意味が違う。しかも「読めてしまう」ので、辞書を引きません。

五、要由零開始嘅三樣五、ゼロから必要な三つ

講咗咁多優勢，都要老實講返：以下三樣，中文完全幫唔到手。 利点を並べましたが、正直に言うと、次の三つは中国語がまったく助けになりません。

① 助詞（は・が・を・に・で）① 助詞（は・が・を・に・で）

中文靠語序，日文靠助詞。呢個係最大嘅分別，亦係最難嘅一關。 中国語は語順で示し、日本語は助詞で示します。ここが最大の違いで、最も難しい関門です。

② 動詞變化② 動詞の活用

中文動詞唔變形。日文一個動詞可以變十幾個樣。呢個要死練。 中国語の動詞は形を変えません。日本語は一つの動詞が十数通りに変化します。ここは反復するしかありません。

③ 敬語③ 敬語

中文都有禮貌講法，但係日文係成套語法系統，唔係換個詞咁簡單。 中国語にも丁寧な言い方はありますが、日本語の敬語は文法体系そのもので、語を置きかえるだけでは済みません。

呢個網站大部分內容係日文寫嘅，不過因為有漢字，中文母語者其實睇得明大半。下面標咗邊啲版有中文。 このサイトの多くは日本語で書かれていますが、漢字があるので中国語話者は大半が読めます。下に、中国語があるページを示しました。

同形異義詞嘅中文意思，以香港・台灣嘅用法為準；大陸用法可能略有出入。 同形異義語の中国語の意味は、香港・台湾の用法を基準にしています。中国大陸の用法とは異なる場合があります。
