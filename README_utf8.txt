■ 直したもの

  【文字化け】

    月会○   → 月会費        sports・gym    「費」が別の字（U+8CB9）になっていた
    市民の○様 → 市民の皆様    midori         「皆」が別の字（U+76BA）になっていた
    映画○賞会 → 映画鑑賞会    event          「鑑」が別の字（U+9D91）になっていた
    料金表○時間あたり） → 料金表（1時間あたり）  shisetsu
    みどり市/教育委 → みどり市/教育/委員会   midori（印が途中で切れていた）
    みどり市/市民館 → みどり市/市民/会館     shisetsu（同上）

  ※ この文書は Windows の文字コードで保存しているため、化けていた字そのものは
    書けません。かわりに ○ と、その字の番号（U+…）を示しています。

  「料金表○時間あたり）」は、HTMLの文字コード指定のセミコロンが1つ落ちていたのが
  原因です。「（」と「1」がくっついて、どのフォントにも無い文字になっていました。

  【中身の食い違い】…読み直したときに見つかったもの

■ 直さなかったもの（理由つき）

  次の2つは「直すと、いまの設問の答えが変わってしまう」ので、そのままにしました。

    shisetsu  中会議室（20名）1,000円 と 大会議室（50名）1,000円 が同額。
              値段の差がないのは作りとして弱いのですが、N3の2問
              （「日曜10時～17時に大会議室で何円」＝7,000円、
                「50人で3時間の最低料金」＝3,000円）が
              この1,000円で成り立っています。

    nihongo   Bクラス「N4～N3」とCクラス「N4～N2」が重なっている。
              ただしN4の2問目（「N4を勉強したい。木曜は仕事」＝BとC）が
              この重なりを前提にしています。

  どちらも「図と設問をセットで直す」なら直せます。ご希望があればお知らせください。
