NIHONGO NO HEYA
〜としたら・〜とすれば・〜とすると
if we suppose that ~
N3 仮定条件
意味
仮定条件「もし〜と考えたら」
事実かどうか分からないことを仮に成り立つと考えて、そのときどうなるかを述べます。うしろには判断・推量・質問が来ることが多い文型です。三つの形は、かたさと使う場面が少しずつちがいます。
コアイメージ
左が点線の箱なのがポイントです。本当かどうかは分からないまま、話を進めます。
接続
［普通形］＋ としたら
［普通形］＋ とすれば
［普通形］＋ とすると
「〜とした場合」「〜と仮定すると」も同じ意味です。
いっしょに使うことば
うしろによく来る形
〜だろう〜はずだ〜かもしれない〜ますか〜べきだ
例文
としたら
彼が知らないとしたら、だれも連絡しなかったのだろう。
If he does not know, then presumably nobody contacted him.
としたら
一億円もらえるとしたら、何に使いますか。
If you were given a hundred million yen, what would you spend it on?
とすれば
この計画を実行するとすれば、予算が足りない。
If we are to carry out this plan, the budget is insufficient.
とすると
あと三十分かかるとすると、開演には間に合わないな。
If it takes another thirty minutes, we will not make the start.
とすれば
この資料が正しいとすれば、結論は変わってくる。
If these materials are correct, the conclusion changes.
にた文型とのちがい
三つの形の使い分け
意味はほぼ同じですが、文体と使う場面が少しずつちがいます。
〜としたら〜とすれば／とすると
文体話しことばとすれば＝書きことば寄り
使う場面特定の場面の仮定とすれば＝一般的な仮定
感じ想像・空想にもとすると＝当然の帰結
○ 生まれ変われるとしたら、何になりたい？　→ 空想
○ 需要が伸びるとすれば、増産が必要だ。　→ 一般的な議論
〜たら・〜なら
「たら」「なら」も仮定ですが、「としたら」は仮定であることをはっきり示す点がちがいます。
○ 雨が降ったら、中止します。　→ ふつうの条件
○ 雨が降るとしたら、午後でしょう。　→ 仮に考えると
ほかのことばで
EN
Supposes something to be true and states what would follow.
中文
假如……的話；如果……
