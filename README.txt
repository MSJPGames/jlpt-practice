生活の日本語（新しい入口）
========================================

【入っているファイル】

  seikatsu.html   「生活の日本語」ページ（新規）
  manabu.html     日本語を学ぶ（カードを1枚追加・上書き）
  sitemap.xml     seikatsu を追加（上書き）

  すべて jlpt-practice フォルダに置いてください。


【なぜ1ページ作ったか】

  防災ゲームを manabu.html に直接ぶら下げることもできましたが、
  「生活の日本語」という枠を先に作りました。

  理由は、ここが これから増えるところ だからです。
  病院のかかり方、役所の手続き、住まいのルール。
  そのたびに manabu.html にカードが増えていくと、
  「日本語を学ぶ」の性格がぼやけます。

  枠を作っておけば、次からは seikatsu.html に足すだけで済みます。


【manabu.html の変更】

  「会話を練習する」の下に1枚追加しました。

      生　生活の日本語
          日本でくらすために。ごみの出し方、じしん・大雨のときの
          行動（やさしい日本語・多言語）

  並び順は 字 → 法 → 話 → 生 → 試 → 教 にしました。
  話と生は「日本語をつかう」もの、試と教は別の目的なので、
  近いものを隣にしています。
  既存のカードの書式・色の付け方に合わせてあります。


【seikatsu.html の中身】

  ・冒頭の一文
      「しけんには 出ませんが、まちがえると こまる 日本語です。」
    ここのページの性格を最初に言っておく必要があると考えました。

  ・🗑️ ごみの 分け方・出し方（10言語・ゲーム）
  ・🚨 じしん・大雨の とき（14言語・ゲーム）

  ・下に「これから ふやしていきます」の枠
      びょういん／役所／すまい を挙げ、
      「これが 分からなくて こまった があれば 教えてください」
    と書いてあります。元学生さんに聞くときの入口にもなります。

  ナビは「‹ 日本語を学ぶ」＋「🏠 トップ」。
  他のページと同じ書式で作ってあります。
