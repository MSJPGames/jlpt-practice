  ■ 最有力候補は 豊田市

      愛知県はインドネシア人が全国1位。

      インドネシア語・タイ語・タガログ語・ネパール語の
      ごみ資料を公開しています。

      規約は「引用される場合は広報課までお問い合わせください」
      ＝ 禁止ではなく、許諾申請型です。

      　豊田市 市長公室 広報課
      　電話 0565-34-6604（問い合わせフォームあり）

      伝える内容（案）

      　・ごみ分別ゲームの多言語表示に、貴市のインドネシア語版の
      　　用語（区分名・品目名）を使いたい
      　・文章ではなく単語レベル。出典は画面に明記する
      　・無料公開

      断られても、現状の表示は続けられます。

  ■ 分かった構造

      インドネシア語の資料が充実 → 地方の中小市 → 権利留保が多い
      オープンデータが整備       → 政令市       → インドネシア語が無い

      名古屋市（9言語）にもインドネシア語はありませんでした。
      愛知県が1位でも、その中心都市とは限りませんでした。

      言語によって当たるべき自治体の性格が違います。
