【繁體中文はそのままです】

  繁體中文は、香港の語彙に合わせて当サイトが作ったものです。
  大阪市の簡体中文版で上書きすると、香港の読者向けという
  いちばんの特徴が消えてしまいます。維持しました。

      生ごみ    简:厨房垃圾和厨余垃圾  繁:廚餘（蔬菜碎屑）
      段ボール  简:硬纸箱             繁:紙箱
      蛍光灯    简:荧光灯             繁:壞掉的光管
      冷蔵庫    简:冰箱               繁:舊雪櫃

  なお「一般垃圾」のように簡繁で字が同じ語は、
  同じ表記のままで正しいものです。
