【bunkei.html の変更】
  この20枚に対応するカードに k（解説ページのファイル名）を足しただけです。
  ほかは1文字も変えていません（k を取りのぞくと元と同じになることを機械で確認）。
    「くわしい解説」ボタン … 320 → 340
    詳細ページ            … 307 → 327

【中身の作り】既存ページとまったく同じ形です
  意味 → コアイメージ（図）→ 接続 → いっしょに使うことば → 例文
  → ほかの用法 → にた文型とのちがい → ほかのことばで → 関連
  ・図は1枚あたり2～3枚、全部あたらしく描きました。
  ・例文は各6本（合計120本）、全部あたらしく書きました。
    市販教材からの引き写しはありません。会社名・人名は架空です。
  ・にた文型どうしで相互リンクを張っています
    （～ておく／～てしまう／～ていく・～てくる、～ずに／～たまま、
    　～はずだ／～だろう／～つもりだった、～たがる／～らしい、
    　～と／～ばいい　など）。
