N3 聴解 182本の音声を作り直すための一式（2026-08-14）

■ なぜ作り直しが要るか
  ★1～★15で、**182本すべて台本が変わりました**（そのままの音声は1本もありません）。
  台本の字数は 15,253字 → 33,804字（2.2倍）。本試験より短すぎた台本を直したためです。

  ★いま公開中のサイトは、画面（新しい）と音声（古い）が食いちがっている可能性があります。
    とくに 概要理解・発話表現・即時応答 は画面に番号しか出ないので、
    音声が古いままだと答えようがありません。急ぎ差し替えてください。

■ つかいかた
  1) pip install edge-tts
  2) この3つを同じフォルダに置く
       make_audio.py
       n3_listening_manifest.json
       file_to_daimon.json
  3) python make_audio.py
       → 同じフォルダの audio/ に n3_q1_01.mp3 … が182本できます

  ・途中で止まっても、もう一度実行すれば **できていないぶんだけ** 作ります
  ・ぜんぶ作り直す:      python make_audio.py --force
  ・1つの大問だけ:       python make_audio.py --only 概要理解
  ・声を耳で確かめる:     python make_audio.py --test
       → test_N.mp3 / test_F.mp3 / test_M.mp3 ができます

  **ffmpeg は要りません。** 無音は mp3 のフレームを並べて作っています。

■ ★声の設定を、いまのものにそろえてください
  make_audio.py のいちばん上の VOICE を見てください。

      N（ナレーター） Nanami  rate -10%  pitch -10Hz
      F（女）        Nanami  rate  +0%  pitch +10Hz
      M（男）        Keita   rate  +0%  pitch  +0Hz

  これは当方が置いた仮の値です。**いまお使いの生成プログラム（.py）に書いてある値**が
  あるはずなので、そちらに合わせてください。合わせないと、これまでの音声と声が変わります。
  （その .py を送っていただければ、こちらで合わせます）

■ 入っている間（公式CDを実測した値。問題間の時間は入れません）
  課題理解     場面＋設問 →2.0秒→ 会話 →2.2秒→ 設問
  ポイント理解   場面＋設問 →2.0秒→ 会話 →2.2秒→ 設問
  概要理解     場面 →2.1→ 話 →2.0→ 設問 →2.0→ 肢1 →3.0→ 肢2 →3.0→ 肢3 →3.0→ 肢4
  発話表現     場面＋設問 →2.0→ 肢1 →2.1→ 肢2 →2.1→ 肢3
  即時応答     発話 →2.0→ 肢1 →2.1→ 肢2 →2.1→ 肢3

■ マニフェストを1か所直しました
  選択肢の読み上げ行に "choice": 1 の印を付けました（396行）。
  これが無いと、本文の行と選択肢の行を見分けられません
  （実際、見分けられずに間が入らない不具合が出たので直しました）。
  いまお使いの生成プログラムは、知らないキーを無視するので影響はありません。

■ かかる時間のめやす
  読み上げ 1,217回・33,804字。ネットワーク次第ですが 1～2時間くらいだと思います。
  1本できるごとに「のこり約〇分」と出ます。

■ うまくいかないとき
  ・「certificate verify failed」… 会社や学校のネットワークだと edge-tts が
    つながらないことがあります。ふつうの回線でお試しください。
  ・途中で何本か失敗しても、最後に一覧が出ます。もう一度実行すればそのぶんだけ作り直します。
