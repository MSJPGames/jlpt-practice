【聴解 もんだい4「即時応答」10問 書き直し】

■ 何を直したか
　61問を全部読み比べたところ、同じやりとりが二つずつありました（9組・10問）。
　　・「完了報告 → 上司がねぎらう」が2問
　　・「くだけた否定的な見通しに同意する」が2問
　　・「期待が裏切られたぼやき → 同情」が3問
　　・「遠慮の表明 → 打ち消して受け入れる」が2問

　もっと深いのは誤答の作り方でした。ほとんどの問題が
　　①相手の言葉を字義どおり／逆に取り違えたもの　②事実がずれるもの
　という同じ二枚組でできていて、音を聞かずに「明るいほう二枚を捨てる」だけで
　解けてしまう状態でした。

　10問を、それぞれ別のやりとりで作り直しました。
　　一点だけの聞き返し／条件をつけて受ける／弁明／謙遜／前倒しの申し出／
　　選んだ理由を言う／心配を打ち消す／責任を引き受ける／理解の確認／
　　遠回しの催促に期日で答える

■ ついでに見つけた穴
　書き直しの途中で、選択肢の書き出しに手がかりが出ていました。
　　・「では／じゃあ」で始まる肢が8本あって、8本とも誤答
　　・「私が」で始まる肢が3問で誤答
　　・「もう済んだ／過去形」の誤答が10問中6問
　これらは音を聞く前に切れてしまいます。書き出しも終わり方も、
　正解と誤答の両方に散らし、検査（verify_m4.py）で見るようにしました。

■ 確かめたこと
　・二重正解 0件（正解をふせて別の担当が4回解き直し、4回とも全問一致）
　・音声にしたときに読みが割れる語 0か所
　・全5468問がエラーなしで「正解」判定
　・「即時応答」61問の正解のかたより … 最長33.3％／最短33.3％
　　（3択なので理想は33.3％。書き直す前は34.4％／32.8％でした）
　・サイト全体5468問 … 最長25.1％／最短25.3％
