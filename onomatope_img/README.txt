オノマトペ 画像フォルダ
=======================

このフォルダに画像を入れると、onomatope.html の各語カードに自動で表示されます。

■ ファイル名のつけ方
  語ごとに決まった名前があります。別ファイル
  「onomatope_image_names.md」を見て、その名前で保存してください。
  例）きらきら → kirakira.png ／ ぐるぐる → guruguru.png

■ 形式
  ・PNG（.png）または GIF（.gif）
  ・まず .png を探し、なければ .gif を探します。
  ・白背景・シンプル・110ピクセル程度の正方形がおすすめ。
  ・1枚あたり 30〜80KB 程度に抑えると軽く表示されます。

■ ポイント
  ・全部そろえなくてOK。入れた分だけ表示されます。
  ・画像が無い語は、今まで通り文字だけの表示になります。
  ・ひらがな版・カタカナ版が同じ音のものは、1枚で両方に表示されます。

■ GitHub へのアップロード
  onomatope.html と同じ場所に、この onomatope_img フォルダごと置いてください。
