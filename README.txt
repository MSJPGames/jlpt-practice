繁體中文の入口ページ
====================================

【入っているファイル】

  chinese_start.html   「用中文底子學日文」入口ページ（新規）
  langdata.js          多言語データ（4言語に入口を登録）

  どちらも jlpt-practice フォルダの中に置いてください。
  langdata.js は上書きになります。


【chinese_start.html とは】

  中国語話者向けの入口ページです。目次ではなく、
  「中国語の下地で日本語を学ぶとどうなるか」の解説を兼ねています。

  ・同じ形で同じ意味の語（12語）
  ・音読みが予測できること（広東語ならさらに有利）
  ・繁體 / 日本の新字体 / 大陸の簡体字 の三者比較（12組）
  ・同形異義語 18組  ← ここが中心
  ・中国語が助けにならない三つ（助詞・活用・敬語）
  ・サイト内の各ページへの導線（中国語あり／日本語のみを明示）

  繁體中文が主で、右上のボタンで日本語に切り替わります。


【langdata.js の変更】

  次の4言語に、この入口ページを登録しました。
    yue  広東語
    zhtw 台湾華語
    nan  台湾語（台語）
    zh   中国語（普通話）

  広東語には、すでに登録済みの音読み・倉頡と並びます。


【まだ残っていること】

  この入口ページは、いまのところ言語カードの中だけにあります。
  トップページか「多言語を学ぶ」から直接リンクを張ると、
  もっと見つけてもらいやすくなります。

  index.html か gaikokugo.html を送っていただければ、
  リンクを追加した版をお返しします。
